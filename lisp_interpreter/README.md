# Lisp Interpreter

A minimal C-based Lisp interpreter project with a REPL, parser, AST, and basic object support.

## Getting Started

Requirements:
- `gcc` or any other C compiler (and be sure to change `CC` flag in `Makefile`)
- `make`

Build the interpreter:
```sh
make
```

Run the interpreter:
```sh
./main.out
```
